# Mambo 2017 · La XXXV rumbo a Río

Memoria interactiva en español de la participación del velero **Mambo Liceo Naval** en la Regata Buenos Aires–Río de Janeiro 2017 y del regreso de la tripulación.

Incluye el track GPS con reproducción, una capa separada para el regreso narrado, el relato íntegro de Raúl Horacio Adinolfi en seis capítulos POV, el video de Ricardo Franzosi y enlaces a Facebook y a *Proa al Centro* Nº 177–179.

La capa de regreso es una reconstrucción editorial, no un track GPS. El material fotográfico pertenece al archivo de la tripulación y se utiliza con autorización de sus autores para esta memoria.

Para GitHub Pages, subir el contenido de esta carpeta a la raíz del repositorio y conservar `data/track.json`. Luego elegir **Settings → Pages → Deploy from a branch → main → /(root)**.
